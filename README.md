# Logbook Coach

Telegram Mini App для фитнес-тренера: учёт клиентов, статусы активности и журнал тренировок.

## Экраны (макеты)

В папке `project/` лежат три экрана в формате холста Design:

- `Main.dc.html` — список клиентов со статусами (активен / пропустил 2+ / риск ухода) и блок «Кому написать».
- `Client.dc.html` — карточка клиента: красный флаг, график рабочего веса с линией цели, прогноз, три последние тренировки.
- `Logger.dc.html` — экран клиента: план дня, подходы, строка быстрого ввода «присед 80 на 8».
- `canvas.json` — расположение экранов на холсте.

Данные в макетах вымышленные.

## Идея MVP

1. Клиент записывает подход за 2-3 тапа или строкой «присед 80 на 8».
2. Тренер видит список со статусами и красными флагами.
3. Бот напоминает клиенту и тренеру.
4. Карточка клиента: последние тренировки и график по одному упражнению.

## Стек

Vite + React + TypeScript, Telegram Mini App SDK (скрипт `telegram-web-app.js`).
План: Supabase (база, авторизация через Telegram, cron для напоминаний), хостинг на Vercel или GitHub Pages.

## Запуск

Нужен Node 22.18 или новее.

```bash
npm install     # при первом запуске создаст package-lock.json, его нужно закоммитить
npm run dev     # открыть адрес из консоли
npm test        # тесты логики статусов (встроенный раннер Node, без зависимостей)
npm run build
```

## Что уже есть в коде

- `src/domain/status.ts` — правила статусов (активен / пропуски / риск ухода) и флаг «написать клиенту». Пороги в одном месте.
- `src/domain/format.ts` — склонения, «3 дня назад», инициалы, вес с запятой, даты и подходы.
- `src/domain/progress.ts` и `nudge.ts` — темп и прогноз до цели, тексты «кому написать».
- `src/data/mockClients.ts` — вымышленные клиенты с тренировками и весами за 8 недель, пока нет базы.
- `src/screens/` и `src/components/` — экран «Клиенты» (`project/Main.dc.html`) и карточка клиента с графиком (`project/Client.dc.html`).
- `src/telegram/` — тема из Telegram, нативная кнопка «Назад», отклик вибрацией.
- Вкладка «Спортсмены»: загрузка программы подготовки к старту по ссылке на Google Таблицу тренера (лист = неделя), отметки подходов, максимумы против нормативов КМС/МС/МСМК, проценты от максимума. Разбор — `src/domain/program.ts` и `prescription.ts`, чтение .xlsx — `src/data/xlsx.ts`.
